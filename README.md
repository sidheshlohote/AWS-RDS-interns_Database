# AWS RDS Interns Database

## 📌 Project Overview

This project demonstrates how to create and manage a MySQL database using **AWS RDS** and **MySQL Workbench**.

The project includes an `Interns` table that stores basic information about interns, including their name, role, and email address.

## 🛠️ Technologies Used

- MySQL
- MySQL Workbench
- AWS RDS
- SQL

## 📂 Database Structure

### Database
`mydb`

### Table
`Interns`

| Column | Data Type | Description |
|---|---|---|
| Name | VARCHAR(100) | Intern's name |
| Role | VARCHAR(100) | Intern's role |
| Email | VARCHAR(150) | Intern's email address |

## 💻 SQL Operations

The project demonstrates the following SQL operations:

- Creating a database
- Selecting a database
- Creating a table
- Inserting records
- Retrieving records using `SELECT`
- Viewing available databases and tables

## ☁️ AWS RDS

The MySQL database was hosted on **Amazon RDS**.
